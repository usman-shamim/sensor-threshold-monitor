# Mission: Understanding the SentinelGUI Codebase

## Why
You completed CS50P (Python fundamentals) and used SpecKit Plus to generate a real
production-grade project — SentinelGUI, a SCADA-style reactor monitoring dashboard.
The code exists and works, but you didn't write it line by line yourself. The goal is
to understand it deeply enough that you can modify it confidently, explain it to others
(exhibition judges, educators), and extend it with new features.

## Success looks like
- You can open any file in the repo and explain what it does and why it's structured that way
- You can add a new fault type or a new sensor without asking for help
- You can explain the threading model to someone who asks why the UI never freezes
- You can demo the system at the exhibition and answer technical questions from engineers
- You can read a Python traceback and find the broken file yourself

## Constraints
- CS50P background: solid on Python basics (functions, files, loops, dicts, classes intro)
- No prior experience with GUIs, threading, or serial communication
- Learning in short sessions alongside development work
- Goal is practical understanding, not academic completeness

## Out of scope
- Deep customtkinter widget internals
- Matplotlib rendering pipeline internals
- Arduino / embedded C firmware
- Formal software engineering theory (design patterns by name, etc.)
